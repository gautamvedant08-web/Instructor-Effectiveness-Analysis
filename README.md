
# Instructor Effectiveness Analysis

This project analyzes instructor performance using student engagement and learning data. The goal is to understand which factors influence course effectiveness and classify instructors into Low, Medium, and High performance tiers.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## What I Did
- Performed data cleaning and EDA.
- Created visualizations to understand the data.
- Calculated weighted effectiveness scores.
- Grouped instructors into three performance tiers.
- Built a Random Forest classification model.
- Evaluated the model's performance.

## Model Result
- Model: Random Forest Classifier
- Accuracy: 95.83%
